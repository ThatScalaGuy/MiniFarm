# 08 – Jahreszeiten, Wetter und Tageszeit

> Jahreszeiten sind **Stimmung und Rhythmus**, kein Druck. Sie geben dem Hof Abwechslung, vermitteln `world.time` (Zeitverständnis) und liefern natürliche Anlässe für Teilaufgaben. Nichts stirbt, nichts verdirbt, nichts läuft ab.

## 1. Grundprinzipien

1. **Jede Jahreszeit hat vier Hoftage** (siehe Doc 03). Der Wechsel geschieht über Nacht-Zeitraffer mit einer kleinen Zeremonie (Pelle kündigt an: „Schau mal, der Frühling kommt!“).
2. **Das Kind kann die Jahreszeit ändern** (Jahreskreis-Rad am Hofbaum): Drehen am Rad springt zur nächsten Jahreszeit. So kann das Kind sich „seinen“ Lieblingswinter wünschen, ohne warten zu müssen.
3. **Pflanzen sterben nie.** Was nicht in die Jahreszeit passt, „schläft“ (Beete mit Decke im Winter) und wacht auf, sobald die passende Zeit kommt (siehe Doc 05).
4. **Jede Jahreszeit ist gleichwertig schön** – kein „schlechtes“ Wetter, kein „Notstand“ im Winter.
5. **Kein Donner/Gewitter, kein Sturm.** Wetter ist sanft: Sonne, Wolken, leichter Regen, Schnee, Nebel, Blätterwind.
6. **Reduce Motion / sensorische Schonung:** Partikeleffekte (Regen, Schnee, Blätter) mit Intensitätsregler in den Eltern-Einstellungen.

## 3. Detailplan je Jahreszeit

### 3.1 Frühling – „Alles wacht auf“

| Bereich | Inhalt |
|---|---|
| **Flora** | Blühende Obstbäume, Krokusse, Tulpen, Wiesenblumen; Beete werden „aufgedeckt“ |
| **Fauna** | Küken schlüpfen, Lämmer, Fohlen; Bienen und Schmetterlinge kehren zurück; Frösche am Teich |
| **Felder** | Säsaison für Radieschen, Salat, Erbsen, Karotten, Kartoffeln, Weizen (Hofstufe-abhängig) |
| **Typische Wünsche** | Küken wärmen, Samen säen, Teich besuchen, Blumen für Tilda pflücken, Beete aufdecken |
| **Fest** | **Blütenfest** (Hoftag 4): Girlanden aus Blüten binden (Muster-Aufgabe `perc.shape`), Tanz der Tiere, Pelle bekommt eine Blumenkette |
| **Hofbuch** | „Erstes Küken“, „Erster Regenbogen“, „Erste Tulpe“ |

### 3.2 Sommer – „Sonne, Wasser, Ernte“

| Bereich | Inhalt |
|---|---|
| **Flora** | Sonnenblumen, Mais, Tomaten, Erdbeeren, Wiesen mit Heu |
| **Fauna** | Libellen, Glühwürmchen am Abend, Fische im Teich, Schafe im Schatten |
| **Felder** | Gießen (Wassertank), Ernte: Erdbeeren, Tomaten, Mais, Erbsen |
| **Typische Wünsche** | Eis machen, Tiere abkühlen (Planschbecken), Heu machen und ballen, Sonnenblume zählen, Limo mischen (Saftpresse) |
| **Fest** | **Erntefreudentag** (Hoftag 4): Eisstand im Hofladen, Kinder tanzen mit Tieren, Pelle gräbt einen Knochen aus (süße Überraschung) |
| **Hofbuch** | „Erste Sonnenblume“, „Erstes Eis“, „Glühwürmchen-Nacht“ |

### 3.3 Herbst – „Gold und Kürbisse“

| Bereich | Inhalt |
|---|---|
| **Flora** | Äpfel, Kürbisse, Weizenernte, bunte Blätter, Pilze (nur Dekoration, nicht pflückbar) |
| **Fauna** | Igel, Eichhörnchen, Zugvögel (Vogelschwarm als V-Formation zählen) |
| **Felder** | Mähdrescher, Kartoffelroder, Kürbisse, Kohl |
| **Typische Wünsche** | Äpfel pflücken, Saft pressen, Blätter harken (Haufen → springen), Drachen steigen lassen, Kürbis schnitzen (Gesicht wählen), Igel füttern |
| **Fest** | **Erntedank-Fest** (neutral: „Danke-Fest“; Hoftag 4): gemeinsames Essen, jedes Tier bekommt ein Lieblingsessen, Kind zählt „Danke“-Lichter |
| **Hofbuch** | „Erster Kürbis“, „Igelbesuch“, „Drachenflug“ |

### 3.4 Winter – „Gemütlich und still“

| Bereich | Inhalt |
|---|---|
| **Flora** | Schnee auf Bäumen, Eisblumen am Fenster, immergrüne Hecken; Beete unter Decken |
| **Fauna** | Vögel am Futterhäuschen, Rehe am Waldrand, Fuchsspuren, Tiere im warmen Stall |
| **Felder** | Ruhend; Winter-Alternative: Kohl und Schnittlauch im **Gewächshaus** (Hofstufe 4) |
| **Typische Wünsche** | Futterhäuschen füllen, Schnee schieben (Schneepflug), Schneemann bauen (3 Kugeln: groß/mittel/klein = Größen ordnen), Wolle spinnen, Plätzchen backen, Stall mit Stroh ausstatten |
| **Fest** | **Lichterfest** (Hoftag 4): Laternen aufstellen (Reihenfolge-Muster), Hof leuchtet, Tiere kuscheln. Neutral und inklusiv, ohne religiöse Symbole (siehe §6). |
| **Hofbuch** | „Erster Schneemann“, „Eisblume“, „Sternschnuppe“ |

## 4. Wetter-System

Wetter ist **Stimmungssache**, kein Spielzustand, der Aufgaben erschwert.

| Wetter | Wann | Wirkung auf Spiel |
|---|---|---|
| Sonne | Standard | – |
| Bewölkt | zufällig | Etwas gedämpftes Licht |
| Leichter Regen | Frühling/Herbst, manchmal Sommer | Pflanzen „trinken“ (Gießen entfällt für diesen Tag, Pelle freut sich); Pfützen (Hüpf-Spaß) |
| Regenbogen | nach Regen mit Sonne | Hofbuch-Eintrag, Kamera-Schwenk |
| Nebel | Herbst/Winter morgens | Weiche Szene, Hahn-Ruf; Interaktionen normal |
| Schnee | Winter | Weiße Welt; Schneepflug-/Schneemann-Aufgaben aktiv |
| Wind | Herbst | Blätter, Drachen-Wunsch |

**Wettersteuerung:** Wetter wird **pro Hoftag** gewürfelt (gewichtet je Jahreszeit), das Kind kann **nicht** wählen, aber Pelle erwähnt es immer positiv („Heute regnet es – die Karotten freuen sich!“). Eltern können Wettereffekte reduzieren.

## 5. Tageszeit-Visualisierung

Das Spiel kennt keine Echtzeit-Uhr. Die Tageszeit folgt dem **Sonnenbogen** (Doc 03): aktionsgesteuert.

| Phase | Lichtstimmung | Soundscape | Typische Ereignisse |
|---|---|---|---|
| Morgen | Rosa/Gold, Tau | Hahn, Vögel | Tiere aufwecken, Frühstück |
| Vormittag | Klar, hell | Insekten, Bach | Feldarbeit |
| Mittag | Hell, kurze Schatten | Wärme, Bienen | Picknick (Pelle-Pause), Mittagsruhe der Tiere |
| Nachmittag | Warm, lange Schatten | Wind, Maschinen | Ernte, Laden |
| Abend | Orange → Violett | Grillen, Eulen | „Alle ins Bett“-Ritual, Laternen |
| Nacht (Zeitraffer) | Dunkelblau, Sterne | Sanfte Spieluhr-Melodie | Pflanzen wachsen, Hofbuch-Zusammenfassung |

## 6. Feste und Inklusivität

- Alle Feste sind **neutral gestaltet** (Erntedank → „Danke-Fest“, Winter → „Lichterfest“). Keine religiösen Symbole, keine spezifische Weihnachts-Ikonographie – Eltern können mit dem Kind eigene Rituale ergänzen.
- Feste sind **optionale Höhepunkte**: Sie erscheinen als besonderer Wunsch am letzten Tag der Jahreszeit; sie müssen nicht gespielt werden.
- Fest-Wunsch beinhaltet immer eine **gemeinschaftliche Aktivität** (z. B. alle Tiere versammeln), die in einem **Foto-Moment** endet (Hofbuch-Foto, das Eltern später ansehen können).

## 7. Technische Hinweise

- Jahreszeiten sind **Daten** (`seasons.json`): Skybox/Lichtprofil, Farb-LUT, Partikel-Presets, Pflanzen-Varianten (Material-Swap), Ambient-Sets, Musik-Sets.
- **Material-/Textur-Swaps** zur Laufzeit statt unterschiedlicher Meshes (z. B. Laubbaum: Frühling-Blüte, Sommer-Grün, Herbst-Orange, Winter-Schnee via Shader-Parameter/Blend).
- Übergänge: 3-Sekunden-Blend von Farb-LUT und Partikeln; Audio-Crossfade 4 s.
- **Performance:** Partikel auf iPhone-Basisgeräten begrenzt (siehe Doc 15, Performance-Budget).
